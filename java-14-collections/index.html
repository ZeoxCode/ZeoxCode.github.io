    常见坑

    • ArrayList 按索引查询 O(1)，LinkedList 按索引查询 O(n)
    • HashMap 无序，TreeMap 按 key 排序，LinkedHashMap 保持插入顺序
    • HashSet 依赖 hashCode() 和 equals()，自定义类放入 Set 要覆盖这两个方法
    • 遍历时不能用 list.remove()，要用 Iterator.remove() 或 removeIf()
