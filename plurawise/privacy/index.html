Privacy Policy for PluraWise

PluraWise does not sell user data and does not send user data to the developer's servers.

PluraWise uses browser permissions only to provide its single purpose: allowing users to send one prompt to multiple AI chat websites and compare responses side by side in a unified workspace.

Data handled by the extension may include user prompts, visible AI responses, uploaded files selected by the user, enabled AI site preferences, layout settings, custom AI site URLs, and recent prompt history.

User preferences and prompt history are stored locally in the browser using chrome.storage.local. They are not transmitted to the developer.

When the user sends a prompt or uploads a file, that content is sent only to the AI chat websites selected by the user, such as ChatGPT, Claude, Gemini, DeepSeek, and other user-authorized AI sites. Those websites process data according to their own privacy policies.

PluraWise does not collect health information, financial information, authentication credentials, precise location, or browsing history unrelated to the PluraWise workspace.

PluraWise does not use user data for advertising, creditworthiness, or unrelated purposes.
