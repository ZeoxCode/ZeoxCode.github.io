    C/C++学习总结（五）——循环

    编程语言 > C/C++ C
    Created At : 2016-09-18 00:00
    Count:181
    1. for
    2. while
    3. do-while
    4. break / continue

    for

    注：C89 不允许在 for 内声明变量，需在外部声明。C99 起支持。

    while

    do-while

    区别：do-while 至少执行一次。

    break / continue

    • break：退出整个循环
    • continue：跳过本次，继续下次

    问题： 死循环——循环变量未更新

    解决： 检查循环变量是否在循环体内有更新。

    问题： 数组遍历越界（off-by-one）

    解决： 统一用 i < n，不用 i <= n-1
