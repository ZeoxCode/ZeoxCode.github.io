    常见坑

    • 流用完必须关闭，推荐用 try-with-resources（Java 7+），自动关闭
    • 序列化的类需要定义 serialVersionUID，否则类修改后反序列化会失败
    • transient 字段序列化后为默认值（null/0/false），不是原来的值
    • 路径分隔符：Windows 用 \，Linux/Mac 用 /，用 File.separator 兼容
