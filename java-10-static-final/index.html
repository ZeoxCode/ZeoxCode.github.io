    常见坑

    • 静态方法中不能用 this，也不能直接访问实例变量
    • Integer == Integer 在 -128~127 范围内返回 true（缓存），超出范围要用 .equals()
    • final 引用变量不能重新指向对象，但对象内容可以修改
    • static 代码块在类加载时执行一次，早于构造方法
