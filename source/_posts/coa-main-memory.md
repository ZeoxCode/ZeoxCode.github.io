主存就是平时说的内存。  
程序运行时，指令和数据主要放在主存里。

现代主存通常用 DRAM。

## RAM、ROM、DRAM、SRAM

几个名词先分清：

- RAM：随机访问存储器，断电通常丢失。
- ROM：只读存储器，断电不丢。
- SRAM：速度快，不需要刷新，常用于 Cache。
- DRAM：容量大、便宜，但需要刷新，常用于主存。

为什么 Cache 用 SRAM，主存用 DRAM？  
因为 SRAM 快但贵，DRAM 慢一点但便宜、密度高。

## DRAM 为什么要刷新

DRAM 用电容保存电荷表示 0/1。  
电容会漏电，所以要定期刷新。

这也是 DRAM 和 SRAM 的一个重要区别。

## 内存地址

CPU 访问内存，本质上是给出地址，然后读写该地址的数据。

比如：

```
地址 0x1000 -> 某个字节
地址 0x1001 -> 下一个字节
```

后面操作系统里的虚拟内存，会在这个基础上再加一层地址转换。  
计组里先理解物理内存和地址访问。

key：

- 主存通常是 DRAM，Cache 通常是 SRAM。
- DRAM 便宜容量大，但要刷新。
- 内存可以看成按地址编号的一大片存储空间。
