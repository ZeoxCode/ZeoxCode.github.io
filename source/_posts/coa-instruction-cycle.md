CPU 执行程序，其实是在反复执行一条条指令。

一条指令通常经历：

```
取指 -> 译码 -> 执行 -> 访存 -> 写回
```

不一定每条指令都有所有阶段，但大体可以这么理解。

## 取指

PC 里保存下一条指令地址。  
CPU 根据 PC 去内存中取出指令。

取完后，PC 通常自动加到下一条指令地址。

## 译码

CPU 需要理解这条指令是什么意思。

比如：

- 是加法还是跳转？
- 操作数在哪里？
- 结果写到哪里？

译码阶段会产生控制信号。

## 执行

真正进行运算或控制转移。

比如 ALU 做加法，或者判断分支是否跳转。

## 访存和写回

如果指令需要读写内存，就进入访存阶段。  
如果有结果需要保存，就写回寄存器或内存。

一个重要直觉：

> 程序运行不是一整块执行，而是 CPU 一次只执行一条指令，只是速度非常快。

key：

- PC 决定下一条指令。
- 指令周期就是 CPU 执行一条指令的过程。
- 分支跳转会改变 PC，因此改变程序执行流。
