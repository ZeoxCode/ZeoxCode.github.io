负数怎么放进计算机，是计组里第一个比较绕的点。

最朴素的方法是原码：最高位表示符号。

用 8 位表示：

```
+5 = 0000 0101
-5 = 1000 0101
```

看起来很直观，但问题是加减法不好做，而且有 `+0` 和 `-0` 两个零。

## 反码

反码规则：

- 正数反码等于原码。
- 负数反码是原码符号位不变，其余位取反。

```
-5 原码：1000 0101
-5 反码：1111 1010
```

反码还是有 `+0` 和 `-0` 的问题。

## 补码

补码规则：

- 正数补码等于原码。
- 负数补码 = 反码 + 1。

```
-5 原码：1000 0101
-5 反码：1111 1010
-5 补码：1111 1011
```

补码最关键的好处：

> 加法器可以同时处理加法和减法。

比如：

```
5 + (-5)

0000 0101
1111 1011
---------
0000 0000   最高位进位丢掉
```

结果正好是 0。

## 一个必须记住的范围

8 位补码范围：

```
-128 到 127
```

为什么不是 -127 到 127？  
因为补码只有一个 0，多出来的一个编码给了最小负数。

key：

- 计算机里整数负数通常用补码。
- 补码让减法可以转成加法。
- n 位补码范围是 `-2^(n-1)` 到 `2^(n-1)-1`。
