词法分析背后常用正则表达式和有限自动机。

比如标识符可以粗略写成：

```text
letter (letter | digit)*
```

意思是：第一个字符是字母，后面可以是字母或数字。

整数可以写成：

```text
digit+
```

## 正则表达式做什么

正则表达式描述一类字符串。

例子：

- `[0-9]+`：一个或多个数字。
- `[a-zA-Z_][a-zA-Z0-9_]*`：类似 C 语言标识符。

词法分析器可以用这些规则识别 token。

## 有限自动机

有限自动机像一张状态图。  
读取一个字符，就根据当前状态跳到下一个状态。

比如识别整数：

```text
开始 -> 读到数字 -> 数字状态
数字状态 -> 继续读数字 -> 数字状态
```

如果读到非数字，就停止，说明一个整数 token 结束。

## NFA 和 DFA

粗略记：

- NFA：非确定有限自动机，同一个输入可能有多条路。
- DFA：确定有限自动机，同一个状态遇到同一个输入只有一条路。

实际实现词法分析时，DFA 更适合直接运行。

key：

- 正则表达式描述 token 模式。
- 有限自动机负责识别字符串是否符合模式。
- 词法分析的理论基础就是正则和自动机。
