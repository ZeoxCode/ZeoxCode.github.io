暴力枚举听起来很笨，但它是很多算法题的起点。

真正做题时，不应该一上来就追求最优解。  
先写出暴力，能帮助我们理解问题结构。

## 暴力法做什么

暴力法就是枚举所有可能，然后检查答案。

比如找数组最大值：

```cpp
int ans = a[0];
for (int i = 1; i < n; i++) {
    ans = max(ans, a[i]);
}
```

这是简单枚举，复杂度 `O(n)`，已经很好。

但有些问题暴力会很慢。

## 子集枚举

有 n 个元素，每个元素选或不选，一共有：

```text
2^n
```

个子集。

例如 0/1 背包的暴力思路：

```text
枚举每个物品选不选
检查总重量是否超过背包
更新最大价值
```

如果 n = 30，`2^30` 已经很大。  
如果 n = 100，暴力基本不可用。

## 排列枚举

如果要枚举 n 个元素的所有排列，数量是：

```text
n!
```

旅行商问题的暴力思路就是枚举所有城市访问顺序。  
城市一多，复杂度完全无法接受。

## 暴力法的价值

暴力不是最终答案，但有几个价值：

1. 帮助理解题意。
2. 作为小数据验证。
3. 给优化提供方向。
4. 有些问题规模小，暴力就够。

比如 `n <= 20` 时，子集枚举可能可以接受。  
`n <= 10` 时，排列枚举有时也能跑。

## 从暴力到优化

很多高级算法都是在暴力基础上减少重复。

比如斐波那契：

```cpp
int fib(int n) {
    if (n <= 1) return n;
    return fib(n-1) + fib(n-2);
}
```

这是暴力递归，会重复计算很多子问题。

加记忆化：

```cpp
int memo[N];

int fib(int n) {
    if (n <= 1) return n;
    if (memo[n] != -1) return memo[n];
    return memo[n] = fib(n-1) + fib(n-2);
}
```

复杂度从指数级降到 `O(n)`。

这就是动态规划的影子。

## 经典例题

两数之和：

暴力：

```cpp
for (int i = 0; i < n; i++)
    for (int j = i + 1; j < n; j++)
        if (a[i] + a[j] == target)
            return true;
```

优化：

```cpp
unordered_set<int> seen;
for (int x : a) {
    if (seen.count(target - x)) return true;
    seen.insert(x);
}
```

这个变化很典型：用数据结构减少枚举次数。

key：

- 暴力枚举是理解问题的起点。
- 暴力是否可用，要看数据规模。
- 优化常常来自减少重复枚举或用数据结构加速查询。
