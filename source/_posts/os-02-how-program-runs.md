一个程序从源代码到运行，大概会经过：

```
源代码 -> 编译 -> 链接 -> 可执行文件 -> 装入内存 -> 运行
```

以前写程序时只关心编译能不能过，现在发现操作系统关心的是后半段：可执行文件怎么被加载，内存怎么分配，CPU 怎么开始执行第一条指令。

运行中的程序叫进程。进程不只是代码，还包括：

- 地址空间
- 寄存器状态
- 打开的文件
- 栈和堆
- 进程控制信息

所以程序是静态的文件，进程是动态运行起来的程序。
