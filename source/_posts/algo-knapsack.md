背包问题是动态规划最经典的题型。

## 0/1 背包

有 n 个物品，每个物品有重量 `w[i]` 和价值 `v[i]`。  
背包容量是 `C`。每个物品只能选一次，求最大价值。

状态定义：

```text
dp[i][j] = 前 i 个物品，在容量 j 下的最大价值
```

第 i 个物品有两种选择：

不选：

```text
dp[i-1][j]
```

选：

```text
dp[i-1][j-w[i]] + v[i]
```

转移：

```text
dp[i][j] = max(dp[i-1][j], dp[i-1][j-w[i]] + v[i])
```

前提是 `j >= w[i]`。

## 空间优化

二维可以优化成一维：

```cpp
for (int i = 1; i <= n; i++) {
    for (int j = C; j >= w[i]; j--) {
        dp[j] = max(dp[j], dp[j - w[i]] + v[i]);
    }
}
```

注意容量要倒序。

为什么倒序？  
因为每个物品只能选一次。如果正序，会在同一轮重复使用当前物品。

## 完全背包

完全背包中，每个物品可以选无限次。

一维写法：

```cpp
for (int i = 1; i <= n; i++) {
    for (int j = w[i]; j <= C; j++) {
        dp[j] = max(dp[j], dp[j - w[i]] + v[i]);
    }
}
```

这里容量正序。  
因为允许重复选当前物品。

## 0/1 背包 vs 完全背包

| 类型 | 每个物品 | 容量循环 |
|---|---|---|
| 0/1 背包 | 最多一次 | 倒序 |
| 完全背包 | 无限次 | 正序 |

这个区别很关键。

## 经典变形

背包不一定问最大价值，也可能问：

- 是否能凑出某个和。
- 凑出某个和有多少方案。
- 最少用多少物品。
- 恰好装满时最大价值。

状态和初始化要跟目标变化。

比如“是否能凑出和”：

```cpp
dp[0] = true;
for (int x : nums) {
    for (int j = target; j >= x; j--) {
        dp[j] = dp[j] || dp[j - x];
    }
}
```

key：

- 0/1 背包每个物品只能选一次，一维容量倒序。
- 完全背包可以重复选，一维容量正序。
- 背包题最重要的是状态含义和初始化。
