语法分析需要规则。  
这些规则通常用上下文无关文法来描述。

一个简单表达式文法：

```text
E -> E + T | T
T -> T * F | F
F -> (E) | id
```

这里：

- E 表示表达式。
- T 表示项。
- F 表示因子。

这个文法自然表达了乘法优先级高于加法。

## 推导

比如：

```text
id + id * id
```

可以从 E 一步步推导出来：

```text
E
=> E + T
=> T + T
=> F + T
=> id + T
=> id + T * F
=> id + F * F
=> id + id * id
```

这个推导过程对应语法树。

## 二义性

如果一个字符串能生成多棵不同语法树，这个文法就是二义的。

例如表达式文法如果写得太简单：

```text
E -> E + E | E * E | id
```

那么 `id + id * id` 可能有两种解释。  
实际语言必须规定优先级和结合性，避免语义不清。

key：

- 文法描述 token 如何组成程序结构。
- 推导过程可以形成语法树。
- 二义性会导致同一段代码有多种解释。
