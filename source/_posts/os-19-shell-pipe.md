Shell 本身也是一个程序。

它读取用户输入，解析命令，然后创建进程执行。

管道 `|` 可以把前一个命令的输出接到后一个命令的输入：

```bash
cat a.txt | grep hello
```

重定向可以改变标准输入输出：

```bash
ls > files.txt
cat < files.txt
```

这里用到的其实是文件描述符。  
标准输入是 0，标准输出是 1，标准错误是 2。

Unix 的设计很巧：文件、管道、终端都可以通过类似的读写接口处理。
