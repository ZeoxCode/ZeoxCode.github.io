HTTP 是应用层协议，浏览网页主要靠它。

不能忘的点：

- HTTP 是请求-响应模型。
- HTTP 本身是无状态的。
- URL、方法、状态码、Header 是理解 HTTP 的核心。

常见方法：

- GET：获取资源
- POST：提交数据
- PUT：整体更新
- DELETE：删除资源

状态码大致分五类：  
2xx 成功，3xx 重定向，4xx 客户端错误，5xx 服务端错误。
