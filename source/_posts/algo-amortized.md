均摊分析不是平均情况分析。

它关心的是：

> 一连串操作的总成本分摊到每一次操作上是多少。

有些操作偶尔很贵，但不经常发生。  
如果把总成本平均看，每次仍然很便宜。

## 动态数组扩容

vector / ArrayList 这类动态数组，容量不够时会扩容。

假设每次满了就扩成原来的 2 倍。

插入一个元素通常是 `O(1)`。  
但扩容时要把旧元素全部复制到新数组，可能是 `O(n)`。

那插入到底是不是 `O(1)`？

单次最坏是 `O(n)`。  
但均摊是 `O(1)`。

## 为什么均摊 O(1)

假设连续插入 n 个元素。

扩容发生在容量：

```text
1, 2, 4, 8, ...
```

总复制次数大概：

```text
1 + 2 + 4 + ... + n < 2n
```

再加上 n 次正常插入，总成本仍然是 `O(n)`。

分摊到每次插入：

```text
O(1)
```

## 栈的例子

有些数据结构操作也可以均摊分析。  
比如一个栈支持 push、pop、multi-pop。

单次 multi-pop 可能弹出很多元素。  
但每个元素最多被 push 一次、pop 一次。

所以一串操作总成本仍然可控。

## 均摊和平均的区别

平均情况分析依赖输入概率分布。  
均摊分析不依赖概率，是对任意操作序列的总成本分析。

这点很重要。

key：

- 均摊分析看一串操作的总成本。
- 动态数组扩容单次最坏 `O(n)`，均摊插入 `O(1)`。
- 均摊不是概率平均，而是确定性的总成本分摊。
