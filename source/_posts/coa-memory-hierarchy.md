CPU 很快，内存慢，磁盘更慢。  
如果 CPU 每次都等内存或磁盘，性能会很差。

所以计算机里有存储器层次结构：

```
寄存器
Cache
主存
磁盘
```

越靠上：

- 速度越快
- 容量越小
- 价格越贵

越靠下：

- 速度越慢
- 容量越大
- 价格越便宜

## 为什么这个结构有效

因为程序有局部性。

### 时间局部性

刚访问过的数据，之后很可能还会访问。

比如循环变量、函数里的局部变量。

### 空间局部性

访问了某个地址附近的数据，之后很可能访问相邻地址。

比如数组连续遍历：

```c
for (int i = 0; i < n; i++) {
    sum += a[i];
}
```

访问 `a[i]` 后，很可能马上访问 `a[i+1]`。

Cache 正是利用局部性，让 CPU 尽量从更快的地方拿数据。

key：

- 存储层次是在速度、容量、成本之间折中。
- 局部性是 Cache 能工作的根本原因。
- 程序写法会影响缓存命中率。
