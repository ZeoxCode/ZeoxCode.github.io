词法分析是编译的第一步。

源代码一开始只是一串字符：

```c
int sum = a + 10;
```

词法分析器要把它切成一个个 token：

```text
int      -> keyword
sum      -> identifier
=        -> operator
a        -> identifier
+        -> operator
10       -> number
;        -> delimiter
```

这一步有点像读文章时先分词。  
还没理解句子结构，只是先知道每个“词”是什么。

## 词法分析关心什么

它关心的是：

- 关键字
- 标识符
- 数字
- 字符串
- 运算符
- 分隔符
- 注释和空白

空格、换行、注释一般不会进入后面的语法分析，除非语言本身对缩进敏感。

## 一个小坑

比如：

```c
ifx = 1;
```

这里 `ifx` 是标识符，不是 `if` 加 `x`。  
词法分析要按最长匹配原则，把它识别成一个完整标识符。

key：

- 词法分析输入字符流，输出 token 流。
- token 有类型和值。
- 词法分析还不理解语句结构，只负责切词。
