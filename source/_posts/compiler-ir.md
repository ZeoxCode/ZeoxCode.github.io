编译器一般不会直接从语法树生成机器码。  
中间通常会有一种中间表示，叫 IR。

为什么需要 IR？

因为源语言很多，目标机器也很多。  
如果每种语言都直接生成每种机器码，组合会爆炸。

有了 IR，可以变成：

```
前端：源语言 -> IR
后端：IR -> 目标机器代码
```

这样结构清楚很多。

## 三地址码

一种常见中间代码是三地址码。

表达式：

```c
x = a + b * c;
```

可以变成：

```text
t1 = b * c
t2 = a + t1
x = t2
```

每条语句最多包含三个地址：两个操作数和一个结果。

这种形式更接近机器执行，也方便优化。

## 临时变量

上面的 `t1`、`t2` 是编译器生成的临时变量。  
它们用来保存中间结果。

后面代码生成时，这些临时变量可能被分配到寄存器或内存。

key：

- IR 是源代码和目标代码之间的桥。
- 三地址码适合表达中间计算过程。
- IR 让优化和代码生成更容易。
