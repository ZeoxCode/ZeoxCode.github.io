## 分类

- 算术：`+` `-` `*` `/` `%`
- 关系：`==` `!=` `>` `<` `>=` `<=`
- 逻辑：`&&` `||` `!`
- 赋值：`=` `+=` `-=` `*=` `/=`
- 位运算：`&` `|` `^` `~` `<<` `>>`

## 整数除法

```c
int a = 5 / 2;  // 结果是2，不是2.5
```

## 优先级（记不住就加括号）

`!` > 算术 > 关系 > `&&` > `||` > 赋值

---

**问题：** `=` 与 `==` 混淆
```c
if (a = 0) { ... }  // 赋值，不是比较，编译不报错但逻辑错误
```
**解决：** 常量写左边，写错时编译器会报错
```c
if (0 == a) { ... }
```

---

**问题：** `i++` 与 `++i` 在表达式中行为不同
```c
int i = 5;
int a = i++;  // a=5, i=6（先用后加）
int b = ++i;  // i=7, b=7（先加后用）
```
**解决：** 单独使用时无区别，在表达式中注意区分。
