I/O 数据传输如果全靠 CPU 搬，会很浪费。

比如磁盘读一大块数据到内存，如果每个字节都要 CPU 参与：

```
磁盘 -> CPU -> 内存
```

CPU 会被大量搬运工作占住。

DMA 的思想是：

> 让设备和内存直接交换数据，CPU 只负责发起和收尾。

## DMA 过程

大概过程：

1. CPU 告诉 DMA 控制器：从哪里读、写到哪里、传多少。
2. DMA 控制器接管总线。
3. 设备和内存直接传输数据。
4. 传输完成后，DMA 发中断通知 CPU。

这样 CPU 可以去做别的事情。

## DMA 和中断的关系

DMA 不是不用 CPU。  
CPU 仍然要设置 DMA 参数，也要在完成后处理中断。

只是数据搬运过程不再由 CPU 一个字节一个字节做。

## 经典理解

普通 I/O 像老板亲自搬货。  
DMA 像老板安排物流搬货，自己只下单和验收。

key：

- DMA 减少 CPU 参与大量数据搬运。
- DMA 适合磁盘、网卡等大块数据传输。
- DMA 完成后通常用中断通知 CPU。
