计算机内部只处理二进制。  
但二进制本身没有意义，意义是人规定出来的。

比如同样的 `01000001`：

- 当成无符号整数，是 65。
- 当成 ASCII 字符，是 `A`。
- 当成机器指令的一部分，可能表示某种操作。

所以 key 是：

> 位串没有天然含义，解释规则决定含义。

## 进制转换

二进制转十进制：

```
1011₂ = 1*2³ + 0*2² + 1*2¹ + 1*2⁰ = 11
```

十六进制常用来简写二进制：

```
1111 1111₂ = FF₁₆
```

一个十六进制位正好对应 4 个二进制位，所以看内存地址、机器码时经常用十六进制。

## 编码

字符也要编码。  
ASCII 里：

```
'A' = 65
'a' = 97
'0' = 48
```

后来字符变多了，才有 Unicode、UTF-8 这些编码。

这里容易犯的错：  
数字字符 `'1'` 和数字 `1` 不一样。

```text
'1' 的 ASCII 是 49
数字 1 的二进制表示是 00000001
```

这也解释了为什么文件、字符串、整数在内存里都是二进制，但解释方式不同。
