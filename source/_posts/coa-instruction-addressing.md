指令就是 CPU 能执行的命令。  
一条指令通常包含两部分：

```
操作码 + 地址码
```

操作码说明做什么，比如加法、跳转、读内存。  
地址码说明操作数在哪里。

## 一条指令不一定直接带数据

比如：

```
ADD R1, R2
```

意思可能是把 R1 和 R2 的值相加。  
这里操作数在寄存器里。

但也可能有：

```
LOAD R1, [1000]
```

意思是从内存地址 1000 取数据到 R1。

## 常见寻址方式

寻址方式就是找到操作数的方法。

常见几种：

- 立即寻址：操作数直接写在指令里。
- 直接寻址：指令里给出内存地址。
- 间接寻址：指令给出的地址里，还存着真正地址。
- 寄存器寻址：操作数在寄存器里。
- 寄存器间接寻址：寄存器里存的是内存地址。

## 小例子

假设：

```
内存[100] = 200
内存[200] = 999
R1 = 100
```

如果是直接寻址 `LOAD A, [100]`，取到的是 200。  
如果是间接寻址，先看 100 里面是 200，再去 200 取，得到 999。  
如果是寄存器间接寻址 `[R1]`，R1 是 100，所以取内存[100]，得到 200。

key：

- 指令要说明“做什么”和“数据在哪”。
- 寻址方式决定如何找到操作数。
- 直接、间接、寄存器间接最容易混，要用例子区分。
