最小生成树是图算法里的经典贪心问题。

问题：

> 给一个连通无向带权图，选一些边把所有顶点连起来，并且总权值最小。

生成树有两个要求：

- 连通所有顶点。
- 没有环。

如果有 n 个顶点，生成树一定有 `n-1` 条边。

## Kruskal 算法

Kruskal 的想法很直接：

```text
把所有边按权值从小到大排序。
依次选边。
如果这条边不会形成环，就加入答案。
```

判断是否成环，用并查集。

代码思路：

```cpp
sort(edges.begin(), edges.end(), byWeight);

for (auto& e : edges) {
    if (find(e.u) != find(e.v)) {
        unite(e.u, e.v);
        ans += e.w;
    }
}
```

复杂度主要是排序：

```text
O(E log E)
```

Kruskal 适合边比较稀疏的图。

## Prim 算法

Prim 的想法像从一个点慢慢长出一棵树。

过程：

1. 从任意点开始。
2. 每次选择连接“树内点”和“树外点”的最小边。
3. 把新点加入树。

用优先队列可以高效实现。

Prim 更像 Dijkstra，都是从一个集合向外扩展。

## 为什么贪心正确

最小生成树有一个割性质：

> 对任意一个割，跨越这个割的最小边，一定可以属于某棵最小生成树。

Kruskal 每次选当前最小的不成环边，本质上是在安全地加入某个割上的最小边。

## 经典例题思路

如果题目说：

```text
要修路把所有村庄连通，修每条路有成本，求最低成本。
```

这基本就是最小生成树。

如果图不连通，就不存在生成树。  
有时题目会变成最小生成森林。

## Kruskal vs Prim

| 算法 | 思路 | 常用数据结构 | 适合 |
|---|---|---|---|
| Kruskal | 按边从小到大选 | 并查集 | 稀疏图 |
| Prim | 从点集合向外扩展 | 优先队列 | 稠密图也常用 |

key：

- 最小生成树连接所有点，总权值最小，无环。
- Kruskal 按边选，Prim 按点扩展。
- 两者都是贪心，正确性依赖割性质。
