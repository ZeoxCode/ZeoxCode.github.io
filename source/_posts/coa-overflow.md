计算机里的整数位数是有限的，所以运算结果可能装不下。  
这就是溢出。

以 8 位有符号补码为例，范围是：

```
-128 ~ 127
```

如果计算：

```
100 + 50 = 150
```

数学上没问题，但 150 超过了 8 位补码最大值 127，就会溢出。

## 怎么判断有符号溢出

一个简单判断：

- 两个正数相加，结果变成负数，溢出。
- 两个负数相加，结果变成正数，溢出。
- 一正一负相加，不会有有符号溢出。

例子：

```
  0110 0100   100
+ 0011 0010   50
-----------
  1001 0110   结果符号位变成 1
```

两个正数加出来变负数，说明溢出。

## 进位不等于溢出

这里容易混。  
无符号数看进位，有符号补码看符号是否异常。

比如：

```
1111 1111 + 0000 0001 = 0000 0000
```

如果当无符号数看，是 255 + 1，产生进位。  
如果当有符号数看，是 -1 + 1 = 0，没有溢出。

同样一串位，解释方式不同，结论也不同。

key：

- 溢出来自位数有限。
- 有符号溢出重点看符号异常。
- 无符号进位和有符号溢出不是一回事。
