词法分析只知道 token，语法分析要看这些 token 能不能组成合法句子。

比如：

```c
int x = a + b * 3;
```

词法分析看到的是：

```text
int, x, =, a, +, b, *, 3, ;
```

语法分析要判断它是不是一条合法声明语句，并且分析表达式结构。

## 为什么需要语法树

表达式：

```text
a + b * 3
```

不是从左到右简单算。  
因为乘法优先级比加法高。

语法树大概是：

```text
    +
   / \
  a   *
     / \
    b   3
```

树的结构表达了运算顺序。

## 语法错误

比如：

```c
int = x 3;
```

词法分析可能还能切出 token，但语法分析会发现它们组合不合法。

这就是平时编译器报的 syntax error。

key：

- 语法分析输入 token 流，输出语法树。
- 语法树表示程序结构。
- 运算优先级和结合性会体现在语法树里。
