以太网是局域网里最常见的链路层技术。
如果一台电脑通过网线接到交换机，大概率就在使用以太网。

## MAC 地址是什么

MAC 地址是网卡的硬件地址，通常写成这样：

```
00:1A:2B:3C:4D:5E
```

它工作在链路层。
在同一个局域网里，设备之间通过 MAC 地址发送以太网帧。

## 以太网帧里有什么

一个以太网帧大概包含：

- 目的 MAC 地址
- 源 MAC 地址
- 类型字段
- 数据
- 校验字段

目的 MAC 表示这一帧要交给谁。
源 MAC 表示这一帧是谁发出来的。

## 交换机怎么工作

交换机工作在链路层。
它会学习 MAC 地址和端口之间的关系。

比如：

```
端口 1 -> A 的 MAC
端口 2 -> B 的 MAC
```

当交换机收到一个目的 MAC 是 B 的帧，就知道应该从端口 2 转发出去。

如果交换机不知道目的 MAC 在哪里，它可能会广播到多个端口。

## IP 和 MAC 的区别

这点很容易混。

- IP 地址用于网络层，帮助跨网络定位主机。
- MAC 地址用于链路层，帮助在当前链路内找到下一跳。

访问外网时，目的 IP 是远程服务器。
但目的 MAC 往往是本地网关。

## 经典例题

**问题：主机 A 和主机 B 在同一个局域网，A 给 B 发数据时，目的 IP 和目的 MAC 是谁？**

答案：

- 目的 IP：B 的 IP 地址。
- 目的 MAC：B 的 MAC 地址。

因为它们在同一局域网，A 可以直接通过 ARP 找到 B 的 MAC，然后把帧发给 B。

## 不能忘的点

- MAC 地址属于链路层，IP 地址属于网络层。
- 交换机根据 MAC 地址转发帧。
- 同网段通信时，目的 MAC 是目标主机；跨网段通信时，目的 MAC 是网关。
