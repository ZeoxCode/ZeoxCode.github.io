以前说 CPU，就是“处理器”。  
但计组里要拆开看：CPU 里面主要有运算器、控制器、寄存器。

## 运算器

运算器负责做算术和逻辑运算。

比如：

- 加法
- 减法
- 与、或、非
- 比较大小

核心部件是 ALU。

## 控制器

控制器负责指挥整个 CPU 的动作。

它会根据当前指令，发出控制信号：

- 该不该读内存
- 哪个寄存器输出
- ALU 做什么运算
- 结果写回哪里

如果把 CPU 当成一个工厂，控制器就像调度员，ALU 像加工机器。

## 寄存器

寄存器是 CPU 内部的小容量高速存储。

常见寄存器：

- PC：下一条指令地址。
- IR：当前指令。
- 通用寄存器：临时保存数据。
- 标志寄存器：保存运算结果状态，比如零标志、进位标志。

为什么需要寄存器？  
因为 CPU 比内存快很多，如果每次运算都去内存拿数据，会慢得多。

key：

- CPU = 运算器 + 控制器 + 寄存器。
- PC 指向下一条指令。
- 寄存器是 CPU 和内存速度差之间的一个缓冲。
