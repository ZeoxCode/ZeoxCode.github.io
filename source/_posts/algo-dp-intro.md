动态规划是算法课里最重要也最容易卡住的一块。

它通常用于：

> 一个问题可以拆成子问题，而且子问题会重复出现。

这时候如果暴力递归，会重复计算。  
动态规划就是把子问题结果存下来。

## 从斐波那契开始

暴力递归：

```cpp
int fib(int n) {
    if (n <= 1) return n;
    return fib(n-1) + fib(n-2);
}
```

问题是 `fib(n-2)` 会被算很多次。

记忆化：

```cpp
int memo[N];

int fib(int n) {
    if (n <= 1) return n;
    if (memo[n] != -1) return memo[n];
    return memo[n] = fib(n-1) + fib(n-2);
}
```

自底向上：

```cpp
dp[0] = 0;
dp[1] = 1;
for (int i = 2; i <= n; i++) {
    dp[i] = dp[i-1] + dp[i-2];
}
```

## DP 的两个关键性质

### 最优子结构

原问题的最优解可以由子问题的最优解组成。

例如最短路径中，最短路径的一段也应该是对应子问题的最短路径。

### 重叠子问题

不同递归路径会反复求同一个子问题。

如果没有重叠，分治就够了，不一定需要 DP。

## 写 DP 的步骤

我觉得可以按这几步：

1. 定义状态：`dp[i]` 表示什么。
2. 写转移：`dp[i]` 从哪些状态来。
3. 初始化：最小问题的答案。
4. 遍历顺序：保证用到的状态已经算过。
5. 返回答案：最后要什么。

## 状态定义最重要

很多 DP 难，不是难在代码，而是难在状态定义。

比如：

```text
dp[i] 表示前 i 个元素的最优解
```

或：

```text
dp[i][j] 表示前 i 个物品、容量 j 的最大价值
```

状态定义清楚，转移才有方向。

## DP 和贪心的区别

贪心每一步只保留一个选择。  
DP 会保留多个子问题状态。

如果局部最优不能保证全局最优，往往要考虑 DP。

key：

- DP = 最优子结构 + 重叠子问题。
- 状态定义是最关键的一步。
- 记忆化是自顶向下，递推是自底向上。
