代码优化不是改变程序结果，而是在保持语义不变的前提下，让程序更好。

“更好”可能是：

- 更快
- 更省内存
- 指令更少
- 访存更少

## 常量折叠

```c
int x = 2 * 3 + 4;
```

编译时就能算出来：

```c
int x = 10;
```

不需要运行时再计算。

## 公共子表达式消除

```c
x = a * b + c;
y = a * b + d;
```

`a * b` 计算了两次，可以先保存：

```c
t = a * b;
x = t + c;
y = t + d;
```

## 死代码删除

```c
x = 1;
x = 2;
```

如果第一次赋值之后从未使用，`x = 1` 就可能被删掉。

## 优化也有限制

编译器不能随便改代码。  
如果优化改变了可观察行为，就是错误优化。

多线程、I/O、volatile、浮点数精度都会让优化变复杂。

key：

- 优化必须保持语义不变。
- 常量折叠、公共子表达式、死代码删除很经典。
- 优化不是越激进越好，要考虑语言规则和运行环境。
