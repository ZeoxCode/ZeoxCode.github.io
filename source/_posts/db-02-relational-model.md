## 基本概念

- **关系**：一张二维表
- **元组**：表中的一行
- **属性**：表中的一列
- **域**：属性的取值范围
- **主码（主键）**：唯一标识元组的属性组
- **外码（外键）**：引用另一张表主键的属性

## 三类完整性

```
实体完整性：主键不能为 NULL
参照完整性：外键必须是被参照表中存在的主键值（或NULL）
用户定义完整性：业务规则，如年龄 > 0
```

## 关系代数

### 基本运算

```
选择 σ：从表中选出满足条件的行
  σ_{age>20}(Student)

投影 π：从表中选出指定的列
  π_{name,age}(Student)

笛卡尔积 ×：两张表的所有行两两组合

并 ∪、差 -、交 ∩：要求两表同结构
```

### 连接运算

```
自然连接 ⋈：在笛卡尔积基础上，选出公共属性值相等的行，并去掉重复列
等值连接：公共属性值相等，但保留重复列
```

## 常见坑

- 自然连接会**消除重复列**，等值连接不会
- 笛卡尔积结果行数 = 表A行数 × 表B行数，列数 = 两表列数之和
- 差运算 A-B：在A中但不在B中的元组，**不满足交换律**
