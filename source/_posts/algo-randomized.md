随机化算法是一个很有意思的思想：

> 在算法中主动引入随机选择，让算法在期望意义上表现更好。

最典型的例子是随机化快速排序。

## 为什么快排要随机

普通快速排序如果总选最后一个元素做 pivot，遇到已经有序数组时可能退化到 `O(n^2)`。

随机选 pivot 后，输入数据很难稳定地把算法卡到最坏情况。

代码：

```cpp
int idx = l + rand() % (r - l + 1);
swap(a[idx], a[r]);
int p = partition(a, l, r);
```

随机化不改变最坏理论上界，但让坏情况出现概率很低。

## Las Vegas 和 Monte Carlo

随机化算法可以粗略分两类。

Las Vegas：

- 答案一定正确。
- 运行时间随机。
- 随机化快排可以这样理解。

Monte Carlo：

- 运行时间通常固定或可控。
- 答案可能有小概率错误。
- 一些随机素性测试属于这一类。

## 随机采样

有时数据太大，不能全部处理。  
可以随机采样估计整体特征。

比如估计一个大数据集的平均值，不一定每次都全量扫描。  
随机抽样可以快速得到近似结果。

但采样要注意偏差。样本不代表总体时，结论会错。

## 随机化的好处

- 避免某些构造性最坏输入。
- 算法简单。
- 平均表现好。
- 可用于近似和估计。

## 风险

- 结果可能不稳定。
- 调试更难。
- 需要理解概率意义。
- 安全场景要用可靠随机源。

比如密码学里不能随便用普通 `rand()`。

key：

- 随机化常用于降低坏输入影响。
- Las Vegas 保证正确但时间随机。
- Monte Carlo 时间可控但可能小概率错误。
