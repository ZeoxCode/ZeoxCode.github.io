字符串 DP 里，最长公共子序列和编辑距离很经典。

## 最长公共子序列 LCS

子序列不要求连续，但相对顺序不能变。

比如：

```text
abcde
ace
```

`ace` 是 `abcde` 的子序列。

状态：

```text
dp[i][j] = s1 前 i 个字符 和 s2 前 j 个字符 的 LCS 长度
```

转移：

如果最后字符相同：

```text
dp[i][j] = dp[i-1][j-1] + 1
```

如果不同：

```text
dp[i][j] = max(dp[i-1][j], dp[i][j-1])
```

代码：

```cpp
for (int i = 1; i <= n; i++) {
    for (int j = 1; j <= m; j++) {
        if (a[i-1] == b[j-1])
            dp[i][j] = dp[i-1][j-1] + 1;
        else
            dp[i][j] = max(dp[i-1][j], dp[i][j-1]);
    }
}
```

复杂度：

```text
O(nm)
```

## 编辑距离

编辑距离问的是：  
把字符串 A 变成字符串 B，最少需要多少次操作。

常见操作：

- 插入
- 删除
- 替换

状态：

```text
dp[i][j] = A 前 i 个字符变成 B 前 j 个字符的最少操作数
```

转移：

如果 `A[i-1] == B[j-1]`：

```text
dp[i][j] = dp[i-1][j-1]
```

否则取三种操作最小：

```text
删除：dp[i-1][j] + 1
插入：dp[i][j-1] + 1
替换：dp[i-1][j-1] + 1
```

## 初始化

编辑距离初始化很重要：

```text
dp[i][0] = i
dp[0][j] = j
```

因为把长度 i 的字符串变成空串，要删 i 次。  
把空串变成长度 j 的字符串，要插入 j 次。

## LCS 和编辑距离的共同点

都是二维 DP。  
状态都表示两个前缀之间的关系。

看到两个字符串互相匹配、转换、比较时，可以先想：

```text
dp[i][j] = 第一个串前 i 个 和 第二个串前 j 个 的答案
```

key：

- LCS 看两个前缀的最长公共子序列。
- 编辑距离看两个前缀之间的最少转换操作。
- 字符串 DP 常用 `dp[i][j]` 表示两个前缀。
