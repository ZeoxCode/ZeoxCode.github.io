函数调用不是魔法。  
每次调用函数，运行时都会在栈上分配一块空间，通常叫栈帧。

例子：

```c
int add(int a, int b) {
    int c = a + b;
    return c;
}
```

调用 `add(1, 2)` 时，栈帧里可能有：

- 参数 a、b
- 局部变量 c
- 返回地址
- 上一个栈帧指针
- 临时保存的寄存器

## 返回地址

函数执行完后，要知道回到哪里继续执行。  
所以调用函数时，要保存返回地址。

这就和计组里的 PC 联系起来了。  
函数调用本质上会改变控制流，返回时再恢复。

## 栈为什么适合函数调用

函数调用天然是后进先出：

```text
main 调 f
f 调 g
g 返回
f 返回
main 继续
```

最后调用的函数最先返回，正好符合栈结构。

## 递归

递归函数每调用一次，就有一个新的栈帧。

所以递归太深会爆栈。

key：

- 函数调用依赖运行时栈。
- 每次调用通常对应一个栈帧。
- 返回地址让函数执行完能回到调用点。
