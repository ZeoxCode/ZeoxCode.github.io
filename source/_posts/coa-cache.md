Cache 是 CPU 和主存之间的高速缓存。

它存在的原因很简单：

> CPU 太快，主存跟不上。

如果 CPU 要的数据在 Cache 里，就是命中。  
如果不在，就要去主存取，叫缺失。

## 平均访问时间

一个经典公式：

```
平均访问时间 = 命中率 × Cache 时间 + 缺失率 × 主存时间
```

更常见写法：

```
AMAT = Hit Time + Miss Rate × Miss Penalty
```

例题：

```
Cache 命中时间 1ns
缺失率 5%
缺失代价 100ns

AMAT = 1 + 0.05 × 100 = 6ns
```

虽然主存很慢，但只要命中率高，平均速度就能明显提高。

## Cache 行

Cache 不是一个字节一个字节搬，而是一块一块搬。  
这一块通常叫 Cache line。

这和空间局部性有关：  
访问一个地址后，相邻地址很可能也会被访问，所以一次多搬一点。

## 映射方式

主存块放到 Cache 里，有几种方式：

- 直接映射：一个主存块只能放到固定位置。
- 全相联：可以放到任意位置。
- 组相联：先分组，组内任意放。

直接映射简单但容易冲突。  
全相联灵活但硬件复杂。  
组相联折中。

key：

- Cache 快，是因为它小、离 CPU 近，并利用局部性。
- 命中率对性能影响很大。
- Cache line 和映射方式是理解 Cache 的核心。
