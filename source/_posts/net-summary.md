计算机网络学到最后，不能只记零散名词。
最重要的是把问题串起来。

我觉得整门课可以围绕三个问题理解。

## 问题一：数据怎么送到另一台主机

这个问题主要由网络层解决。

核心概念：

- IP 地址
- 子网
- 路由
- 默认网关

如果目标在同一个网段，可以直接发。
如果不在同一个网段，就交给路由器一跳一跳转发。

不能忘：

> IP 解决主机到主机的问题。

## 问题二：数据怎么送到具体进程

一台主机上有很多程序。
IP 只能找到主机，不能找到进程。

所以传输层引入端口。

核心概念：

- TCP
- UDP
- 端口号
- Socket

不能忘：

> 端口解决进程到进程的问题。

## 问题三：不可靠网络上怎么可靠传输

IP 网络只尽力而为。
丢包、乱序、重复都可能发生。

TCP 通过这些机制提高可靠性：

- 三次握手
- 序号
- ACK
- 超时重传
- 滑动窗口
- 流量控制
- 拥塞控制

不能忘：

> TCP 不是让网络变可靠，而是在不可靠网络上包装出可靠字节流。

## 一张总图

可以这样记：

```
HTTP / DNS       应用层：应用之间怎么交流
TCP / UDP        传输层：进程之间怎么传
IP / ICMP        网络层：主机之间怎么走
Ethernet / ARP   链路层：当前这一跳怎么发
```

一次网页请求大概是：

```
DNS 解析域名
TCP 建立连接
TLS 建立安全通道
HTTP 发送请求
IP 负责跨网络转发
以太网负责每一跳传输
```

## 最经典的一句话

如果整门课只记一句：

> 计算机网络就是把应用数据一层层封装，通过 IP 和路由逐跳转发，到达后再一层层拆开，最终交给目标进程。

这句话里包含了分层、封装、路由、端口和应用通信。

## 不能忘的点

- 分层是主线。
- IP 找主机，端口找进程，MAC 找下一跳。
- TCP 的可靠性来自序号、确认、重传和窗口。
