区间 DP 处理的是一段区间上的最优问题。

常见状态：

```text
dp[l][r] = 区间 l 到 r 的最优解
```

它和普通线性 DP 不太一样，因为转移通常要枚举断点。

## 石子合并

经典问题：

有一排石子，每次可以合并相邻两堆，代价是两堆石子总重量。  
问把所有石子合并成一堆的最小代价。

状态：

```text
dp[l][r] = 合并 l 到 r 这段石子的最小代价
```

如果最后一次合并在 k 处分开：

```text
dp[l][r] = dp[l][k] + dp[k+1][r] + sum(l, r)
```

枚举 k：

```text
dp[l][r] = min(dp[l][k] + dp[k+1][r] + sum(l,r))
```

## 遍历顺序

区间 DP 通常按区间长度从小到大：

```cpp
for (int len = 2; len <= n; len++) {
    for (int l = 1; l + len - 1 <= n; l++) {
        int r = l + len - 1;
        dp[l][r] = INF;
        for (int k = l; k < r; k++) {
            dp[l][r] = min(dp[l][r],
                dp[l][k] + dp[k+1][r] + sum(l, r));
        }
    }
}
```

为什么按长度？  
因为大区间依赖小区间。

## 复杂度

三层循环：

```text
O(n^3)
```

如果 n 比较大，可能需要优化，比如四边形不等式优化，但入门先掌握基础转移。

## 其他区间 DP

常见题型：

- 矩阵链乘法
- 石子合并
- 戳气球
- 回文串区间问题

矩阵链乘法的转移和石子合并很像，都是枚举最后一次断点。

## 区间 DP 的关键问题

每次都问：

```text
这个区间最后一次操作是什么？
```

最后一次操作通常会把区间分成左右两部分。

key：

- 区间 DP 常用 `dp[l][r]`。
- 转移通常枚举断点 k。
- 遍历顺序一般按区间长度递增。
