流水线是计组里很经典的思想。

一条指令执行可以分成几个阶段：

```
取指 -> 译码 -> 执行 -> 访存 -> 写回
```

如果不用流水线，一条指令全部做完，再做下一条。  
如果用流水线，多条指令可以重叠执行。

像洗衣服：

```
洗 -> 烘 -> 叠
```

不用流水线：第一批洗烘叠全做完，再做第二批。  
用流水线：第一批烘的时候，第二批可以开始洗。

## 流水线提高什么

流水线主要提高吞吐率，不一定减少单条指令延迟。

一条衣服还是要经历洗、烘、叠。  
但单位时间能完成更多批。

## 流水线冲突

流水线不是永远顺利，会有 hazard。

### 结构冲突

多条指令同时需要同一个硬件资源。

### 数据冲突

后一条指令需要前一条指令的结果，但结果还没出来。

例子：

```asm
ADD R1, R2, R3
SUB R4, R1, R5
```

第二条要用 R1，但第一条还没写回。

### 控制冲突

分支跳转导致不知道下一条该取哪条指令。

## 怎么解决

常见思路：

- 插入暂停
- 数据转发
- 分支预测
- 增加硬件资源

key：

- 流水线让多条指令重叠执行。
- 它主要提高吞吐率。
- 结构冲突、数据冲突、控制冲突是三类典型问题。
