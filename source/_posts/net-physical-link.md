物理层和链路层在最底下，刚学时容易觉得离应用很远，但它们解决的是最基础的问题：
比特怎么真的从一台机器到另一台机器。

## 物理层解决什么

物理层关心的是最底层的传输介质和信号。

比如：

- 网线里是电信号
- 光纤里是光信号
- 无线网络里是电磁波

它不关心这个比特属于 HTTP 还是 TCP，也不关心 IP 地址。
它只负责把 `0` 和 `1` 变成可以传输的信号。

## 链路层解决什么

链路层比物理层高一点。
它关心的是：在同一段链路上，怎么把一组比特组织成一帧，并送给下一台设备。

链路层会处理：

- 帧的格式
- MAC 地址
- 差错检测
- 局域网内转发

链路层的单位通常叫**帧**。

## 一跳是什么意思

网络不是从源主机一下飞到目标主机，而是一跳一跳走。

比如：

```
我的电脑 -> 家里路由器 -> 运营商路由器 -> ... -> 目标服务器
```

链路层每次只负责其中一段：

```
我的电脑 -> 家里路由器
```

到了下一台路由器以后，会重新封装新的链路层帧，再发往下一跳。

## 经典例题

**问题：链路层能不能把数据直接送到远在国外的服务器？**

不能。

链路层只负责同一链路或同一局域网内的一跳传输。
跨网络找路是网络层 IP 和路由器要解决的问题。

## 不能忘的点

- 物理层负责传输比特。
- 链路层负责把比特组织成帧，并完成一跳传输。
- 链路层不负责端到端通信，它只关心下一跳。
