学 IP 地址时，最关键的不是背 A/B/C 类地址，而是理解：
IP 地址分成**网络号**和**主机号**。

## IP 地址为什么要分网络号和主机号

如果整个互联网只按单个 IP 查找，路由表会非常大。
所以 IP 地址要按网络组织。

比如：

```
192.168.1.23/24
```

这里 `/24` 表示前 24 位是网络号，后 8 位是主机号。

所以：

- 网络号：`192.168.1.0`
- 主机范围：`192.168.1.1` 到 `192.168.1.254`
- 广播地址：`192.168.1.255`

## 子网掩码的作用

子网掩码用来判断 IP 的网络号。

例如：

```
IP:       192.168.1.23
Mask:     255.255.255.0
Network:  192.168.1.0
```

计算方法是 IP 和子网掩码做按位与。

## 判断两个 IP 是否同网段

例题：

```
A: 192.168.1.10/24
B: 192.168.1.20/24
C: 192.168.2.10/24
```

A 的网络号是 `192.168.1.0`。
B 的网络号也是 `192.168.1.0`。
C 的网络号是 `192.168.2.0`。

所以 A 和 B 同网段，A 和 C 不同网段。

同网段可以直接通过链路层发送。
不同网段必须交给路由器。

## 为什么要子网划分

子网划分就是把一个大的网络继续切成更小的网络。

好处：

- 减少广播范围
- 方便管理
- 提高地址利用率

比如一个公司有教学楼、办公楼、宿舍楼，就可以划成不同子网。

## 经典例题

**问题：`192.168.1.130/25` 所在子网的网络地址和广播地址是多少？**

`/25` 表示前 25 位是网络号。
最后一段 8 位中，最高 1 位也属于网络号，所以每个子网大小是 128。

范围分成：

```
192.168.1.0   - 192.168.1.127
192.168.1.128 - 192.168.1.255
```

`192.168.1.130` 在第二段。

所以：

- 网络地址：`192.168.1.128`
- 广播地址：`192.168.1.255`
- 可用主机：`192.168.1.129` 到 `192.168.1.254`

## 不能忘的点

- IP 地址 = 网络号 + 主机号。
- 子网掩码决定网络号有多长。
- 同网段直接发，不同网段找网关。
