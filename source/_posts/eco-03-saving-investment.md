## 金融体系的作用

金融体系的核心功能：把**有钱但不想用**的人（储蓄者）的钱，转移给**想用钱但暂时没有**的人（借款者）。

两种转移方式：
- **金融市场**：储蓄者直接借钱给借款者（买债券、买股票）
- **金融中介机构**：通过银行等中间人（存款→贷款）

## 储蓄 = 投资（封闭经济）

从 GDP 公式推导：
```
GDP = C + I + G
Y - C - G = I
（Y - C - G）= 国民储蓄 = I
```

**结论：在封闭经济中，储蓄恒等于投资。**

- 私人储蓄 = Y - T - C（收入减税后，剩下不消费的部分）
- 公共储蓄 = T - G（政府税收减支出）
- 国民储蓄 = 私人储蓄 + 公共储蓄

> 政府财政赤字（T < G）= 公共储蓄为负 = 挤占了可用于投资的储蓄

## 可贷资金市场

把金融市场理解为一个市场：
- **供给**：想存钱的人提供可贷资金（储蓄者）
- **需求**：想借钱投资的人需要可贷资金（借款者）
- **价格**：利率（借钱的成本）

**利率上升**：
- 储蓄更有吸引力，供给增加
- 借款成本更高，需求减少

**均衡利率**：供给 = 需求时的利率

## 影响储蓄和投资的政策

**储蓄激励政策**（供给右移，利率下降，投资增加）：
- 减税鼓励储蓄（降低资本利得税、利息所得税）
- 养老金账户免税（401k、IRA）

**投资激励政策**（需求右移，利率上升，储蓄增加）：
- 投资税收抵免（企业购买设备可以抵税）

**政府借贷（赤字财政）**（供给减少，利率上升）：
- 政府赤字 → 公共储蓄减少 → 可贷资金供给减少
- 利率上升 → 私人投资被"挤出"
- 这就是著名的**挤出效应（Crowding Out）**

## 股票和债券

**债券（Bond）**：
- 借款凭证，约定利率和还款期限
- 持有人是债权人，到期必须还钱
- 风险较低，收益固定

**股票（Stock）**：
- 企业所有权的一部分
- 持有人是股东，分享利润，也承担亏损
- 风险较高，收益不固定

**为什么股票长期收益高于债券？**
- 风险补偿：股票风险更大，投资者要求更高的回报
- 这个额外的回报叫**风险溢价（Risk Premium）**

## 核心要点

- 金融体系 = 把储蓄转化为投资的机制
- 封闭经济：储蓄 ≡ 投资（恒等式）
- 利率 = 可贷资金的价格，由供求决定
- 政府赤字会挤出私人投资（挤出效应）
- 股票风险高于债券，长期收益也应该更高
