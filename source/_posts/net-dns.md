我们访问网站时通常输入域名，比如：

```
www.baidu.com
```

但网络层真正需要的是 IP 地址。
DNS 解决的就是：

> 怎么把人容易记的域名，转换成机器使用的 IP 地址。

## 为什么不直接记 IP

直接记 IP 有几个问题：

- IP 不好记。
- 网站可能换服务器，IP 会变。
- 一个域名背后可能有多个 IP。
- CDN 会根据地区返回不同 IP。

所以域名更适合给人使用，IP 更适合给网络设备使用。

## DNS 为什么是分层的

DNS 不是一个巨大的表放在一台服务器上。
如果全世界域名都查一台服务器，它会撑不住，也不可靠。

DNS 是分层的：

```
根 DNS
  -> 顶级域 DNS（com、cn、org）
    -> 权威 DNS（baidu.com）
```

查询 `www.baidu.com` 时，大概会逐层问：

1. 根服务器：`.com` 去哪里问？
2. `.com` 服务器：`baidu.com` 去哪里问？
3. `baidu.com` 权威服务器：`www.baidu.com` 的 IP 是多少？

实际中本地 DNS 服务器和缓存会让过程更快。

## DNS 缓存

DNS 查询结果通常会缓存。

缓存位置可能在：

- 浏览器
- 操作系统
- 本地 DNS 服务器
- 路由器

缓存可以减少查询次数，提高访问速度。
但缓存也意味着域名修改 IP 后，不一定立刻对所有人完全生效。

## 经典例题

**问题：为什么有时候修改域名解析后，要等一段时间才生效？**

因为 DNS 有缓存。
之前查询过这个域名的机器，可能还在使用旧的解析结果。等缓存过期后，才会重新查询新的记录。

这个过期时间通常和 DNS 记录里的 TTL 有关。

## 不能忘的点

- DNS 把域名解析成 IP。
- DNS 是分层、分布式的，不是一张集中大表。
- DNS 缓存能加速访问，但也会带来解析延迟生效的问题。
