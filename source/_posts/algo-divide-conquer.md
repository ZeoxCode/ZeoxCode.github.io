分治法的核心很简单：

> 把一个大问题拆成几个相似的小问题，分别解决，再合并答案。

它通常有三步：

```text
Divide：分解问题
Conquer：递归求解子问题
Combine：合并子问题结果
```

## 递归是分治的工具

分治常用递归实现。

例如求数组最大值，可以这样想：

```text
整个数组最大值 = 左半部分最大值 和 右半部分最大值 的较大者
```

代码：

```cpp
int solve(int l, int r) {
    if (l == r) return a[l];
    int mid = (l + r) / 2;
    int left = solve(l, mid);
    int right = solve(mid + 1, r);
    return max(left, right);
}
```

这不是最快写法，扫一遍也行。  
但它体现了分治结构。

## 分治适合什么问题

一般适合：

- 问题能拆成规模更小的同类问题。
- 子问题相对独立。
- 子问题答案能合并成原问题答案。

典型例子：

- 归并排序
- 快速排序
- 二分查找
- 大整数乘法
- 最近点对
- 矩阵乘法优化

## 分治和动态规划的区别

分治的子问题通常不重叠。  
动态规划的子问题通常大量重叠。

比如归并排序，左半和右半互不重叠。  
斐波那契递归里，`fib(n-2)` 会被重复算很多次，这就适合记忆化或 DP。

## 经典例题：二分查找

有序数组查找 x：

```cpp
int binarySearch(vector<int>& a, int x) {
    int l = 0, r = a.size() - 1;
    while (l <= r) {
        int mid = l + (r - l) / 2;
        if (a[mid] == x) return mid;
        if (a[mid] < x) l = mid + 1;
        else r = mid - 1;
    }
    return -1;
}
```

每次把搜索范围缩小一半，所以复杂度是：

```text
O(log n)
```

二分的关键不是代码，而是能不能证明每次都安全地丢掉一半。

key：

- 分治 = 分解、解决、合并。
- 分治依赖递归结构。
- 子问题不重叠时，分治很自然；子问题重叠时，要想到动态规划。
