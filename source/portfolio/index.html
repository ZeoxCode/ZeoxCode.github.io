配置 GitHub Token

持仓数据存储在你的私有仓库 ZeoxCode/ZeoxCode.github.io 中的 holdings.json。
请前往 GitHub → Settings → Developer settings → Fine-grained tokens 生成一个对该仓库有 Contents 读写 权限的 Token，粘贴到下方。

Token 只存在你的浏览器 localStorage 中，不会上传任何服务器。
